# SCORPULSE — Web creativa

Esta es una versión inicial de la web de Scorpulse inspirada visualmente en la referencia proporcionada:
- crema + naranja + rosa
- tipografía display grande
- formas editoriales
- tarjetas de proyectos
- fundadores
- números
- galería masonry
- lightbox
- animaciones al hacer scroll
- responsive para celular

## Cómo usarla

1. Abre `index.html` en VS Code.
2. Ejecuta con Live Server si lo tienes instalado.
3. Sustituye las URLs de Unsplash por las fotografías reales de Scorpulse.
4. Cambia:
   - NOMBRE UNO / NOMBRE DOS
   - números
   - textos
   - correo
   - Instagram / TikTok / Facebook
   - nombres de marcas y proyectos.

## Para usar fotos locales

Por ejemplo:

<img src="img/galeria/foto-01.webp" alt="Campaña Scorpulse" loading="lazy">

Recomendación:
- WebP
- fotografías de máximo 2000–2500 px por lado
- comprimir antes de subir
- nombres tipo `campana-marca-01.webp`

## Librerías

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Google Fonts
- JavaScript vanilla

No necesitas instalar npm para esta versión.
